## 1. 安装

1. 到 [Releases](https://github.com/JackyTJie/SJTURunningMan_Advanced_Edition/releases) 下载 APK；
2. 把 APK 传到手机上（数据线、微信文件传输、网盘均可）；
3. 点击安装。系统可能提示「未知来源应用」——在提示中允许当前来源安装即可。

> 系统要求：Android 8.0（API 26）及以上。`minSdk = 26`、`targetSdk = 34`。

## 2. 登录

1. 应用启动后自动打开 JAccount 登录页获取 Cookie，可手动登录，也可走「交我办」一键登录；
2. 应用会自动检测 Cookie 有效性。失效时自动重新登录；
3. 若反复失败，去系统设置里**清除应用数据**后重来。

## 3. 参数配置

| 参数 | 范围 | 默认 | 说明 |
| --- | --- | --- | --- |
| 跑步次数 | 1–30 次 | 1 | 生成多少条记录。首次建议选 1 次先验证可用性 |
| 开始时间 | 0–23 时、0–59 分 | 08:00 | 每条会加随机波动 |
| 结束日期 | 日期选择器 | 昨天 | 以此为最新一条向前生成 |
| 跳过已有记录的日期 | 开关 | 开启 | 开启后已有记录的那几天挪到更早日期，条数仍等于设定次数；向前最多翻 120 天且不越过学期起点，凑不够时如实提示不足 |
| 目标距离 | 1–5 km | 4 km | 单条目标距离 |
| 自定义路线 | 见下 | 思源湖浪漫跑步路线 | 可在新页面连点设置 |

参数范围来自 `apps/android/app/src/main/java/com/sjtu/runner/config/AppConfig.kt`。

## 4. 学期数据

主界面分四个页面：**跑步工作台 / 路线管理 / 任务日志 / 关于软件**，与电脑版一一对应。

- **「本学期进度」卡片**（跑步工作台）：显示当前学期的**达标公里**与**完成率**。未登录或同步失败时显示 `--`，日历保持占位。
- **「学期日历」**（任务日志）：周一起始、逐月展开本学期每一天。实心绿 = 计入成绩，描边 = 无效记录，灰 = 未跑，空白格 = 不在学期内。服务器未给出学期起止时提示「服务器未返回本学期起止日期。」
- **登录后自动设定跑步计划**：登录成功后的第一次学期数据同步按本学期未完成公里数反推「跑步次数 × 单次距离」（单次 1–5 km、次数不超过 30 次，向上取整保证补上缺口）并填入输入框；这两个值被你手动改过就保持不变，只在日志说明原因。自动填入的值跨启动保留。
- **浮层提示**：登录成功、路线已导入、计划已自动设定等提示浮在页面顶部，5 秒后自动收起，不再把下方内容往下推；同样的文字保留在「任务日志」。
- **「跑步路线」卡片只在「路线管理」页**：「跑步工作台」底部的「预览」会跳到该页预览所选路线。
- 学期数据只在本次会话内展示，**不落盘**；同步失败只记一行日志，不改变登录状态、不会自动登出。

## 5. 开始上传

1. 点「开始任务」按钮；
2. 观察进度条与状态提示；切到其他页面时顶部保留一条紧凑运行栏，可随时停止；
3. 完成后显示成功 / 失败统计。

运行日志区会逐条打印生成与上传进度，多条之间默认间隔数秒。

## 6. 自定义路线

1. 进入路线设计页，在地图上**依次连点**选择坐标点；
2. 点越多越贴合，**注意点是有顺序的，且起始点与终止点越接近越好**；
3. 保存后回到主界面重新开跑。

![路线设计](./images/android-route.webp)

具体的坐标格式、坐标系差异，见 [routes.md](./routes.md)。

## 7. 权限说明

`AndroidManifest.xml` 申请：

| 权限 | 用途 |
| --- | --- |
| `INTERNET` | 访问 pe.sjtu.edu.cn 上传数据、检查更新 |
| `ACCESS_NETWORK_STATE` | 判断网络可用性 |
| `READ_PHONE_STATE` | 读取设备标识（用于请求头构造） |

应用开启了 `usesCleartextTraffic`（校园网环境下偶尔需要明文 HTTP）。

故障排查见 [faq.md](./faq.md)；自行编译见 [build.md](./build.md)。
