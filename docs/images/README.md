## 截图规范

- **尺寸**：手机端按真机分辨率截（安卓/鸿蒙 1080×2340，iPhone 1179×2556 或 1284×2778），不要拉伸。
- **格式**：静态图优先 WebP（`magick in.png -resize 1200x -quality 80 out.webp`），需要广兼容时用 PNG 并压到 300 KB 以内。
- **体积**：单张控制在 300 KB 以内。超过就降质量或降尺寸，不要把原始大图直接提交。
- **命名**：`<平台>-<用途>.png`，全小写、连字符分隔。新图先在本表登记再放进文档。
- **内容**：界面语言保持应用原文（中文），避免出现账号、Cookie、验证码、真实姓名等敏感信息 —— 截图前先登出或打码。
- **裁剪**：只保留相关区域，去掉桌面任务栏、状态栏多余部分；不要加红框箭头外的装饰。

## 生成占位图

占位图由 ImageMagick 生成，新平台按同样方式补：

```bash
FONT="/System/Library/Fonts/Hiragino Sans GB.ttc"
magick -size 1080x2340 xc:'#171a21' -font "$FONT" -gravity center \
  -pointsize 64 -fill '#8b93a7' -annotate 0 "平台 界面\n待替换" docs/images/<平台>-main.png
```
