# iOS 版

这是 SJTU 一键校园跑工具的 iOS 工程（Swift / SwiftUI），版本 `4.5.0`，Bundle ID `SJTU.SJTURunningMan`。

**完整的使用、签名与编译说明请见 [../../docs/ios.md](../../docs/ios.md)** —— 本文件只作为目录内指引。

## 快速开始

```bash
cd apps/ios
open SJTURunningMan.xcodeproj
```

在 Xcode 中配置 Team ID 与 Bundle ID 后即可编译运行，细节见 [docs/ios.md](../../docs/ios.md)。

## 目录内容

```
apps/ios/
├── SJTURunningMan/                 应用源码（SwiftUI 视图、ViewModel、网络与生成逻辑）
├── SJTURunningMan.xcodeproj/       Xcode 工程
└── README.md                       本文件
```
